# המורה הקולית – שברים וסדרות

אפליקציה שמסבירה בקול (קול עברי מובנה) שברים וסדרות לכיתה ד', עם ציורים מונפשים ותרגול בשלוש רמות.

## איך פותחים
- **במחשב:** לחיצה כפולה על `פתח את המורה הקולית.bat` (או פתיחת `index.html` ב־Edge/Chrome).
- **באייפון / לילדה:** https://krmy1979.github.io/hamore-hakolit/ (המאגר `krmy1979/hamore-hakolit` בגיטהאב).

## מבנה הפרויקט
| קובץ | מה יש בו |
| --- | --- |
| `index.html` | שלד הדף |
| `css/style.css` | עיצוב |
| `js/hebrew.js` | הקראת שברים בעברית ("שלושה רבעים") ועיצוב שברים על המסך |
| `js/voice.js` | הקול (Web Speech API, קול עברי) |
| `js/draw.js` | ציורים: פיצות, רצועות, קופסאות, סדרות, גפרורים |
| `js/fractions.js` | 5 יחידות שברים: שיעור + מחולל תרגילים ב־3 רמות |
| `js/sequences.js` | 4 יחידות סדרות: שיעור + מחולל תרגילים ב־3 רמות |
| `js/app.js` | מסכים, מנוע התרגול, רמות, כוכבים, מסך הורים |
| `tools/build.py` | בונה קובץ אחד `dist/index.html` |
| `tools/test.js` | בדיקה אוטומטית של אלפי תרגילים (`node tools/test.js`) |

## איך זה עובד
- **שיעור:** צעדים עם קול וציור, ממשיך לבד; אפשר "שוב", "הקודם", "הבא".
- **תרגול:** סיבובים של 8 שאלות. ניסיון ראשון נכון = 2 כוכבים, שני = כוכב אחד.
- **טעות ראשונה:** הסבר מותאם לסוג הטעות (למשל "חיברת גם את המספרים למטה") + ציור עזר.
- **טעות שנייה:** פתרון מלא צעד אחרי צעד, בקול.
- **רמות:** 4 מתוך 5 נכון בניסיון ראשון → עולים רמה. ברמה 3 → כתר "אלופה".
- **מסך הורים:** התקדמות לפי נושא, הטעויות שחוזרות, הגדרות קול ומהירות.

## קול עברי
- באייפון: מובנה.
- ב־Windows: הגדרות ← זמן ושפה ← דיבור ← הוספת קולות ← עברית.
